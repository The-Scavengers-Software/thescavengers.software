Set up Campfire

This link sets up Campfire, an app for listening to your Audiobookshelf server, so it can connect to a server in one tap. It's meant to open straight in the Campfire app on Android.

If you're seeing this page, Campfire isn't installed on this device, or it couldn't open the link.

Get Campfire

Get it on Google Play Download from GitHub

Once Campfire is installed, go back and tap the link again. If it still opens this page, update Campfire to the latest version and try again.

Or set it up yourself

You can enter the same details by hand in Campfire's sign-in screen:

  1. Enter the server address you were given.
  2. When Campfire says the server is protected by Cloudflare Access, tap Add service token.
  3. Enter the Client ID and Client Secret from your server's admin, then sign in.

The setup details in this link are only meant for the Campfire app. They travel in the part of the link after the #, which your browser never sends to this website, and this page removes them from the address bar as soon as it opens. It doesn't read, show, or keep them.
